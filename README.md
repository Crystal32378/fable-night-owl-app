# Fable Night Owl 飛寶

一隻會學習「你怎麼理解方向」的陪伴貓頭鷹。單一 HTML 檔，無外部函式庫或素材。

直接用瀏覽器開啟 `index.html` 即可（建議 Chrome / Safari，語音需要 zh-TW 語音包）。

- 方向鍵 / WASD 走路，或按住滑鼠、觸控往想去的方向走
- 「新旅程」從捷運象山站出口出發；「迷路觀光客 自動走」一分鐘內看貓頭鷹自己學會怎麼跟你說話
- 目的地：華南銀行國際會議中心（松仁路123號），只有走到松仁路側入口門前 20px 內才算抵達

程式分兩層：`NavEngine`（街道圖、最短路徑、單向路口承諾、每幀狀態分類、偏離 250px 重規劃）與 `Guidance`（只負責把下一步說成方位／左右／地標三種說法）。`UserModel` 記錄每種說法的成敗，連續 3 次失敗即 AVOIDED 並換一種；每第 5 句指令花一次在最少用的說法上（好奇心）。
